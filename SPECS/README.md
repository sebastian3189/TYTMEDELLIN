## Regla operativa

Una tarea lee únicamente el spec que la gobierna y los anteriores que este enlace.
No se cargan los seis por costumbre. El archivo raíz `AGENTS.md` determina agente y
skill obligatorios. Una decisión nueva se escribe en el spec correspondiente; no se
crea otro spec salvo que el alcance sea realmente independiente.
