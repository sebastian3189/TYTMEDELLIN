# ARCHIVADO — Spec 03 anterior

**Origen:** Specs 01 y 02  
**Estado inicial de todas las historias:** Pendiente

## Prioridad P0 — antes de diseñar

| ID | Historia | Criterio de cierre |
|---|---|---|
| DISC-01 | Inventariar datos, marca y fotografías | Cada dato tiene fuente o marca de pendiente |
| DISC-02 | Confirmar oferta y cobertura | Lista aprobada por el cliente |
| DISC-03 | Definir conversión y responsables | WhatsApp y destino de formulario confirmados |
| DISC-04 | Definir tono y promesa | Propuesta de valor aprobada |
| BRAND-01 | Recibir y auditar el logo maestro | SVG/PDF y PNG autorizados, sin reconstrucción |
| BRAND-02 | Aprobar dirección creativa | Un concepto elegido entre máximo tres |
| BRAND-03 | Cerrar paleta y tipografía | Tokens, licencias y contraste aprobados |
| BRAND-04 | Curar el archivo fotográfico | Selección con permisos y propósito por página |
| MOTION-01 | Prototipar movimiento web | Móvil, escritorio y movimiento reducido aprobados |
| MOTION-02 | Aprobar storyboard Higgsfield | Producción continua de 15 s y costo máximo definidos |
| BUDGET-01 | Activar compuerta de créditos | Hook bloquea cualquier proyección superior a 200 |

## Prioridad P2 — después de validar la primera versión

- Descarga de propuesta corporativa.
- Preguntas frecuentes administrables.
- Integración CRM.
- Blog o guías locales.
- Solicitud avanzada para eventos y grupos.
- Gestión de contenidos, solo si el equipo realmente la necesita.

## Definition of Done

Una historia solo pasa a terminada cuando tiene contenido aprobado, estados de carga,
vacío, éxito y error; funciona con teclado y lector de pantalla; se verifica en móvil
y escritorio; no contiene datos inventados; y tiene evidencia de prueba.
